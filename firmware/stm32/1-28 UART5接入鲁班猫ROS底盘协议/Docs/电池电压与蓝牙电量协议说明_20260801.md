# 1-10 电池电压与蓝牙电量

## ADC采样

- 采样引脚：`PC4`。
- ADC外设：`ADC1`，通道 `14`。
- 分压倍率：`11.1`，沿用 `9-1 ADC读取小车电压模拟量` Demo。
- 电量映射：`10.50V = 0%`，`12.60V = 100%`，中间线性换算。
- OLED显示电池转换后的电压和百分比；电压显示精度为 `0.1V`。

## 蓝牙数据包

原有 `0x55 0x51` 雷达状态包保持不变，新增独立电量包，每次原有10ms蓝牙发送节拍同时发送：

| 字节序号 | 内容 | 说明 |
|---:|---|---|
| 0 | `0x55` | 固定包头1 |
| 1 | `0x53` | 电池电量包类型 |
| 2 | 电池电压 | 单位 `0.1V`，例如 `126` 表示 `12.6V` |
| 3 | 电量百分比 | `0~100`，例如 `85` 表示 `85%` |
| 4 | `0x5B` | 固定包尾 |

示例：`55 53 7E 64 5B` 表示电池电压 `12.6V`、电量 `100%`。

注意：电量百分比仅按电压线性估算，带载、内阻和电池化学特性会造成误差；后续如需更准确的剩余容量，需要按实际电池曲线标定。
