## 定时器分配

| 定时器 | 功能 | 引脚/说明 |
| --- | --- | --- |
| TIM2 | 左前轮编码器B | PA15 / PB3，TIM2部分重映射，关闭JTAG并保留SWD |
| TIM3 | 左后轮编码器A | PA6 / PA7 |
| TIM4 | 右前轮编码器C | PB6 / PB7 |
| TIM5 | 右后轮编码器D | PA0 / PA1 |
| TIM6 | 1 ms系统节拍 | 蜂鸣器状态机与10 ms蓝牙遥测调度，无外部引脚 |
| TIM8 | 四路电机PWM | PC6 / PC7 / PC8 / PC9 |

## 掌机接收协议

| 字节 | 掌机按键/功能 | 当前行为 |
| --- | --- | --- |
| `0x5B` | B / 蓝牙模式 | 解除紧急停车锁存，停车等待手动运动命令 |
| `0x5C` | Y / 避障模式 | 切换状态并停车，等待下一阶段接入雷达避障输出 |
| `0x5D` | X / 自主模式 | 切换状态并停车，等待下一阶段接入自主导航输出 |
| `0x49` | A / 紧急停车 | 立即四轮停车并锁存禁用控制，需重新按B/Y/X解除 |
| `0x41` | 前进 | 四轮同速前进 |
| `0x42` | 前进+右转 | 左轮高速、右轮低速 |
| `0x43` | 原地右转 | 左轮前进、右轮后退 |
| `0x44` | 后退+右转 | 左轮高速后退、右轮低速后退 |
| `0x45` | 后退 | 四轮同速后退 |
| `0x46` | 后退+左转 | 左轮低速后退、右轮高速后退 |
| `0x47` | 原地左转 | 左轮后退、右轮前进 |
| `0x48` | 前进+左转 | 左轮低速、右轮高速 |

手动运动命令只在 `0x5B` 蓝牙模式且没有紧急停车锁存时执行。切换任意模式时先停车，避免沿用上一模式的运动命令。

## 蓝牙发送协议

### 雷达状态包

`55 51 前 后 左 右 雷达状态 小车状态 5B`

小车状态字段：`0x00`待机/紧急停车，`0x01`避障模式，`0x02`自主模式，`0x03`蓝牙手动控制。

### 底盘速度包

`55 52 左后 左前 右前 右后 陀螺仪角度 5B`

- 四个速度字段是每10 ms读取一次的编码器有符号脉冲增量。
- 每个速度字段采用 `int8` 二补码；例如 `0x05` 表示 `+5`，`0xFB` 表示 `-5`。
- 超过 `+127/-127` 时分别饱和到 `0x7F/0x81`。
- 陀螺仪角度尚未接入，当前发送 `0x00`。
- 雷达包和底盘包均由TIM6每10 ms调度一次。

## 建议实车验证顺序

1. 架空四个车轮后编译下载，上电时四轮必须保持停车。
2. 发送 `0x41`，确认未按B键时四轮不动作。
3. 发送 `0x5B` 后依次测试 `0x41` 至 `0x48` 的方向和弯转极性。
4. 运动过程中发送 `0x49`，确认四轮立即停车；随后直接发送运动命令应保持停车。
5. 再发送 `0x5B` 解除锁存，然后发送运动命令恢复手动控制。
6. 解析 `55 52 ... 5B` 数据包，架空转动每个轮子并核对四个速度字段顺序和正负方向。
7. 发送 `0x5C`、`0x5D`，确认当前版本只切换状态且始终停车。
