# 鲁班猫 ROS UART5 底盘协议

## 1. 链路参数

| 项目 | 参数 |
|---|---|
| STM32 TX | PC12（UART5_TX） |
| STM32 RX | PD2（UART5_RX） |
| 波特率 | 115200 |
| 格式 | 8 数据位、无校验、1 停止位 |
| 电气连接 | 鲁班猫 TX 接 STM32 PD2，鲁班猫 RX 接 STM32 PC12，双方共地 |

UART5 与 USART2 蓝牙、UART4 ESP32-C3 相互独立。STM32 仅在 UART5 接收中断中写入环形缓冲，控制命令在主循环统一解析，避免中断直接驱动车轮。

## 2. ROS 下行控制命令

UART5 可以直接发送已有蓝牙/WiFi 单字节控制协议，ROS 不需要重新实现一套命令值。

| 字节 | 含义 | 说明 |
|---|---|---|
| `0x41` | 前进 | 四轮前进 |
| `0x42` | 前进右转 | 前进并向右修正 |
| `0x43` | 原地右转 | |
| `0x44` | 后退右转 | |
| `0x45` | 后退 | 四轮后退 |
| `0x46` | 后退左转 | |
| `0x47` | 原地左转 | |
| `0x48` | 前进左转 | |
| `0x49` | 停车 | 立即停车 |
| `0x5B` | 手动模式 | 允许方向命令直接控制底盘 |
| `0x5C` | 遥控局部避障模式 | 方向命令受雷达安全仲裁 |
| `0x5D` | 自主导航模式 | 由 STM32 当前自主逻辑执行 |
| `0x6A` | 减速 | 手动模式降低 PWM 档位 |
| `0x6B` | 加速 | 手动模式提高 PWM 档位 |
| `0x5E` | 鸣笛开启 | 开启远程连续双响 |
| `0x5F` | 鸣笛关闭 | 关闭远程鸣笛 |
| `0x60` | 灯带关闭 | 关闭 8 颗 WS2812 |
| `0x61` | 灯带流水 | 开启 8 颗 WS2812 彩色流水 |
| `0x62` | 灯带闪烁 | 开启 8 颗 WS2812 绿色闪烁 |

建议 ROS 节点启动时先发送 `0x5B`、`0x49`，随后按控制周期发送方向命令；超过 350 ms 未收到运动或停车命令时，STM32 的失联保护会自动停车。

## 3. STM32 上行遥测数据

STM32 每 10 ms 将以下完整数据包分别发送到 USART2、UART4 和 UART5。所有多字节包均按字节顺序发送，无额外转义。

### 3.1 雷达与车辆状态包

固定长度 9 字节：

`55 51 Front Rear Left Right LidarState CarState 5B`

| 索引 | 字段 | 取值 |
|---:|---|---|
| 0 | 包头1 | `0x55` |
| 1 | 包头2 | `0x51` |
| 2 | 前方距离 | 厘米，`0x00~0xFE` 有效，`0xFF` 未知或不小于255 cm |
| 3 | 后方距离 | 同上 |
| 4 | 左侧距离 | 同上 |
| 5 | 右侧距离 | 同上 |
| 6 | 激光雷达状态 | `0x00` 异常/未就绪，`0x01` 工作中 |
| 7 | 小车状态 | `0x00` 待机，`0x01` 避障，`0x02` 自主，`0x03` 手动 |
| 8 | 包尾 | `0x5B` |

### 3.2 电池包

固定长度 5 字节：

`55 53 VoltageDeciV Percent 5B`

电压字段单位为 0.1 V，电量字段范围为 0~100%。

### 3.3 底盘速度包

固定长度 8 字节：

`55 52 LeftRear LeftFront RightFront RightRear GyroscopeAngle 5B`

四路速度是 10 ms 窗口编码器增量的 `int8` 二补码；当前陀螺仪字段为预留单字节，接入 IMU 后由底层更新。

## 4. ROS 节点集成建议

ROS 侧可建立一个 UART5 节点：写入方向命令，读取串口字节流并按 `0x55` 包头、第二字节类型和 `0x5B` 包尾分帧。建议分别统计 `0x51`、`0x52`、`0x53` 三类包的接收时间，超过设定时间没有收到状态包时在 ROS 侧报警。

本协议只负责 STM32 底盘控制与状态回传；第二个激光雷达、IMU 和视觉识别数据由鲁班猫 ROS 节点自行处理，不通过本 UART5 协议强行复用字段。
