# LD-14 串口解析任务报告

## 一、任务信息

- 日期：2026-07-26
- 工程：`1-2 LD-14雷达串口解析`
- 基础工程：复制 `1-0  STM32F103RCT6 基本框架` 后独立开发，未在基础工程内加入雷达代码。
- 目标：通过 USART1 接收 230400 波特率的 LD-14 原始数据，解析后经 USART2 输出，并在 OLED 同步显示运行状态。

## 二、协议与引脚

| 功能 | 外设与引脚 | 参数 |
|---|---|---|
| LD-14 接收 | USART1_RX / PA10 | 230400-8-N-1 |
| LD-14 发送预留 | USART1_TX / PA9 | 230400-8-N-1 |
| 调试输出 | USART2_TX / PA2 | 115200-8-N-1 |
| 调试接收 | USART2_RX / PA3 | 115200-8-N-1 |
| OLED | PA5 / PA4 软件 I2C | 显示帧数、CRC、转速、角度、距离、置信度 |

LD-14 使用固定 47 字节帧，帧头为 `54 2C`，每帧包含 12 个测量点。速度、角度、距离和时间戳按小端格式解析，CRC8 使用 `0x4D` 多项式规则。

## 三、实现结果

- USART1 中断只执行帧同步、CRC8 累计和有效帧发布，不在高速接收中断内打印、刷新 OLED 或进行完整解析。
- 主循环取得最新有效帧后解析 12 个点，并正确处理跨越 0° 的角度插值。
- USART2 每 20 个有效帧输出一次完整 47 字节 RAW、帧字段、12 点解析结果与累计统计，避免 115200 调试口拥塞。
- OLED 同步显示有效帧数、CRC 错误数、转速、起始角度、第 0 点距离与置信度。
- 红灯表示等待有效帧，收到首个有效帧后切换为绿灯；蜂鸣器提供启动提示。

## 八、问题与处理

- USART1 为 230400，而 USART2 为 115200，若逐帧打印完整 12 点会导致调试口积压；采用每 20 个有效帧输出一次解决带宽不匹配。
- 角度帧可能跨越 359.99° 到 0°；解析时先扩展结束角度，完成线性插值后再归一化到 0° 至 359.99°。
- 接收中断与主循环共享最新帧缓冲区；通过发布锁避免主循环复制期间被中断覆盖。
