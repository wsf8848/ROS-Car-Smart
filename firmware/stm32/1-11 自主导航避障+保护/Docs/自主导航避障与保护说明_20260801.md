# 1-11 自主导航避障与保护

## 使用方式

1. 掌机发送 `0x5D`，切换自主导航模式。
2. 小车使用当前底盘速度档位自动前进。
3. 掌机发送 `0x6A`/L2 减速、`0x6B`/R2 加速，实时调整自主前进速度。
4. 掌机发送 `0x49` 可立即停车；重新发送模式键可重新授权。

## 自主路径逻辑

- 前方大于 `70cm`：保持当前速度档位直行。
- 前方进入 `70cm`：比较左右空间，选择更空旷且大于 `55cm` 的方向弧线绕行。
- 前方小于 `25cm`：进入紧急原地转向；左右均不安全则停车等待。
- 前方恢复到 `100cm`：释放绕行状态，恢复自主直行。
- 雷达未就绪、数据超时或距离未知：停车保护。

参数集中在 `Algorithm/AutonomousConfig.h`，现场优先调整 `AUTONOMOUS_FRONT_TRIGGER_CM`、`AUTONOMOUS_SIDE_CLEAR_CM`、`AUTONOMOUS_EMERGENCY_CM` 和 `AUTONOMOUS_CLEAR_MARGIN_CM`。

## 保护逻辑

- 电池百分比小于 `10%`：停车保护。
- 自主直行阶段四轮编码速度差异连续 `3` 次超过阈值：电机保护停车。
- 弧线绕行阶段不比较内外轮绝对速度，避免正常差速被误报。
- 陀螺仪接口 `Autonomous_SetAttitude(PitchDeg10, RollDeg10, Valid)` 已预留；接入后角度单位为0.1度，俯仰/横滚超过 `±20.0°` 停车。

## 调参建议

先用最低速度档位测试单个正面障碍物，再逐步提高速度。若转向太晚，增大 `AUTONOMOUS_FRONT_TRIGGER_CM`；若侧向擦碰，增大 `AUTONOMOUS_SIDE_CLEAR_CM`；若左右抖动，增大 `AUTONOMOUS_CLEAR_MARGIN_CM`；若紧急转向仍距离不足，增大 `AUTONOMOUS_EMERGENCY_CM`。每次只改一个参数。

本版本是基于四向距离的局部避障，不是全局SLAM导航；遇到封闭区域会停车等待，不保证所有复杂环境都能找到出口。

`User/main.c` 未修改。工程已使用 ARMCC 5 编译，结果为 `0 Error(s), 0 Warning(s)`；请使用 DAP 下载后实车验证。
