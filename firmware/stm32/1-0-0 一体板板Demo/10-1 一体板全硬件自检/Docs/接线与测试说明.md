# STM32F103RCT6 一体板全硬件自检说明

## 1. 工程用途

本工程把原 `1-1` 至 `9-1` Demo 中可共存的功能合并到一份固件，覆盖：

- 板载红、绿、蓝 LED
- KEY1、KEY2、KEY3 三个按键
- 板载蜂鸣器
- 板载 OLED
- PC4 电池电压 ADC
- ICM42670 加速度计/陀螺仪在线识别
- 四路电机正转、反转和四路编码器反馈
- 六路舵机信号
- USART1、USART2、UART4、UART5 回环

电机 PWM 与 S1、S2 共用 `TIM8/PC6/PC7`，USART1 与 S4、S5 共用 `PA9/PA10`。固件通过分阶段重配资源解决冲突，电机测试和舵机测试不会同时运行。

## 2. 上电前安全要求

1. 电机测试前必须架空四个车轮，车体固定牢靠，周围不要放手、线缆和松散物品。
2. 第一次测试舵机建议每次只接一个舵机，确认接口顺序后再接多路。
3. 舵机必须使用符合舵机规格的稳定 `5~6V` 电源，电源电流要足够；不要用 STM32 的 `3.3V` 引脚给舵机供电。
4. 舵机电源地、编码器地、USB-TTL 地和主板 GND 必须共地。
5. 3S 电池电压检测按 `10.5~12.6V` 标定。若使用不同电池或板上分压比不同，需要修改 `Hardware/Battery.h`。
6. 没有确认电机和电池极性前，不要让车轮接触地面。

## 3. 烧录接线

使用 J-Link 或 CMSIS-DAP 的 SWD 接口：

| 下载器 | STM32F103RCT6 一体板 |
|---|---|
| SWDIO | PA13 / SWDIO |
| SWCLK | PA14 / SWCLK |
| GND | GND |
| VTref / 3.3V 检测 | 3.3V |
| NRST（可选） | NRST |

主板由自身电源接口供电。下载器的 `3.3V/VTref` 主要用于电平参考，除非明确知道下载器供电能力，否则不要用它给电机和舵机供电。

Keil 工程：`Project.uvprojx`

已生成固件：`Objects/Project.hex`

目标芯片选择：`STM32F103RC`，接口选择 `SWD`。烧录完成后复位运行。

## 4. 外设接线

### 4.1 电机与编码器

按板上丝印把电机动力线接到 A、B、C、D 四路电机端子，把对应编码器的 VCC、GND、A 相、B 相接到同组编码器接口。

| 通道 | 默认车轮位置 | PWM | 方向脚 | 编码器输入 |
|---|---|---|---|---|
| A | 左后轮 | PC6 / TIM8_CH1 | PB0、PB1 | PA6、PA7 / TIM3 |
| B | 左前轮 | PC7 / TIM8_CH2 | PB9、PB8 | PA15、PB3 / TIM2 |
| C | 右前轮 | PC8 / TIM8_CH3 | PB11、PB10 | PB6、PB7 / TIM4 |
| D | 右后轮 | PC9 / TIM8_CH4 | PC5、PB5 | PA0、PA1 / TIM5 |

如果“正转”方向与车辆实际前进方向相反，交换该电机的两根动力线即可。编码器测试只判断正、反转期间是否都有脉冲，不强制某个脉冲符号。

### 4.2 六路舵机

| 舵机接口 | 信号脚 | 定时器通道 |
|---|---|---|
| S1 | PC6 | TIM8_CH1 |
| S2 | PC7 | TIM8_CH2 |
| S3 | PA8 | TIM1_CH1 |
| S4 | PA9 | TIM1_CH2 |
| S5 | PA10 | TIM1_CH3 |
| S6 | PA11 | TIM1_CH4 |

舵机三线通常为 `GND / V+ / Signal`，但不同品牌颜色和插头方向可能不同，必须按舵机标签和板上丝印确认，不能只按线色判断。测试动作限制为 `60° -> 120° -> 90°`，避免直接撞到机械端点。

### 4.3 USART2 调试串口

| USB-TTL | 一体板 |
|---|---|
| RX | PA2 / USART2_TX |
| TX | PA3 / USART2_RX |
| GND | GND |

串口参数为 `115200-8-N-1`。上位机可发送字符 `1` 启动电机测试、`2` 启动舵机测试、`3` 进入串口回环接线页面。

USB-TTL 必须使用 `3.3V TTL` 电平，不能接 RS-232 正负电压接口。

### 4.4 四串口回环接线

按下 KEY3 进入提示页后，用跳线分别短接：

| 端口 | 短接方法 | 波特率 |
|---|---|---|
| USART1 | PA9 与 PA10 | 9600 |
| USART2 | PA2 与 PA3 | 115200 |
| UART4 | PC10 与 PC11 | 9600 |
| UART5 | PC12 与 PD2 | 9600 |

四组都短接后再次按 KEY3，OLED 会显示 `U1 U2 U4 U5` 各自的 `OK/NO`。测试结束后拆掉这些回环跳线，再恢复外部模块接线。

## 5. 实际测试步骤

### 5.1 上电自动测试

烧录并复位后，固件自动执行：

1. OLED 显示 `BASIC TEST`。
2. 红、绿、蓝 LED 各点亮约 300 ms，应能看到三种颜色依次亮起。
3. 蜂鸣器鸣响约 250 ms，应能听到一声短鸣。
4. 读取电池 ADC，主页面第三行显示电池电压。
5. 读取 ICM42670 ID。正常时第二行显示 `IMU:OK 47`；否则显示 `FAIL` 和实际 ID。
6. 进入主页面：`K1:M K2:S K3:U`。

OLED 能正常显示测试页面，本身就是 OLED 通信和显示的目视验证。

USART2 在待机时每秒输出一次 `acc=x,y,z`、`gyro=x,y,z` 和 `temp=x`。缓慢倾斜或转动主板时，对应轴的数据应明显变化；静止时加速度合量应接近重力加速度，陀螺仪应接近零并允许存在少量零偏。

### 5.2 KEY1：电机与编码器

1. 先架空并固定四个车轮。
2. 按 KEY1；蜂鸣器短鸣后还有约 2 秒安全等待。
3. A、B、C、D 每个电机依次正转 600 ms、反转 600 ms，其余电机保持停止。
4. 每一路正、反转期间编码器都至少产生 2 个脉冲才显示 `ENCODER OK`。
5. 最后 OLED 显示 `PASS:x/4`。`4/4` 表示四套电机和编码器自动检测均通过。
6. USART2 同时输出每一路正反转脉冲数，便于定位是哪一路电机、供电或编码器接线异常。

### 5.3 KEY2：六路舵机

1. 确认舵机供电和共地，机构留有活动空间。
2. 按 KEY2。
3. S1 至 S6 依次执行 `60° -> 120° -> 90°`，OLED 显示当前通道。
4. 六路都应按顺序动作一次。固件只能验证 PWM 信号已经发出，不能自动判断舵机内部齿轮和机械负载是否正常，因此最终以目视动作为准。
5. 测试结束后固件关闭舵机 PWM，并恢复电机 PWM 与 USART1 引脚配置。

### 5.4 KEY3：四串口

1. 按 KEY3，看到 `SHORT TX TO RX` 后接好四组回环线。
2. 再按一次 KEY3开始检测。
3. OLED 显示四个端口的 `OK/NO`；全部正常时显示 `ALL PASS`。

## 6. 常见故障判断

| 现象 | 优先检查 |
|---|---|
| 上电完全无显示 | 主板供电、OLED 焊接、PA4/PA5、GND |
| `IMU FAIL` | PB4/PA12、ICM42670 供电、焊接、I2C 上拉 |
| 电机转但编码器 FAIL | 对应编码器 VCC/GND/A/B、插头顺序、码盘供电 |
| 电机完全不转 | 电池/电机电源、驱动使能、动力线、该通道驱动芯片 |
| 舵机抖动或复位 | 舵机电源电流不足、地未共地、插头方向错误 |
| 只有 S4/S5 或 USART1 异常 | PA9/PA10 是分阶段复用引脚，确认测试期间没有外部设备强驱动 |
| 串口回环显示 NO | TX/RX 未短接、接错引脚、外部模块仍占用线路、电平不兼容 |
