## 三、避障状态与安全规则

- `WAIT`：有效环境数据不足，停车。
- `GO`：前方大于90厘米，输出巡航前进指令。
- `SLOW`：前方45至90厘米，按距离线性减速并向空间更大一侧修正。
- `LEFT/RIGHT`：前方25至45厘米，停止前进并选择较空闲一侧原地转向。
- `ESC`：左右侧均受阻，保持停止前进并向平均空间较大一侧旋转。
- `ESTOP`：前方不大于25厘米，全部速度归零并置位急停标志。
- `FAULT`：超过300毫秒没有有效雷达帧，全部速度归零并置位急停标志。

所有障碍物距离统一使用厘米。新障碍物立即写入距离图；历史角度点保留500毫秒，使障碍物消失判断保持保守，并避免雷达单圈有效点密度造成状态抖动。

## 四、OLED与USART2

OLED四行内容：

```text
AVD:GO
F:115 L:011 CM
R:140 B:999 CM
V:+600 W:+000
```

OLED每100毫秒检查一次显示数据，但只重写发生变化的字段，不再先写短横线后覆盖数字，从而避免距离数字横线和整行闪烁。USART2现作为115200-8-N-1蓝牙二进制协议口，不再混发ASCII调试文本；TIM2每10毫秒产生一次发送请求，主循环以100 Hz发送最新九字节遥测帧。

蓝牙遥测协议固定为：

| 字节 | 内容 | 定义 |
|---|---|---|
| 0 | 包头1 | `0x55` |
| 1 | 包头2 | `0x51` |
| 2 | 前方距离 | 单字节厘米值 |
| 3 | 后方距离 | 单字节厘米值 |
| 4 | 左侧距离 | 单字节厘米值 |
| 5 | 右侧距离 | 单字节厘米值 |
| 6 | 雷达状态 | `0x00`异常，`0x01`工作中 |
| 7 | 小车状态 | `0x00`待机，`0x01`避障，`0x02`自主导航，`0x03`蓝牙手动控制 |
| 8 | 包尾 | `0x5B` |

距离字段中`0x00`至`0xFE`表示0至254厘米，`0xFF`表示距离未知或不小于255厘米。手机控制命令为：`0x41`前进、`0x45`后退、`0x47`左转、`0x43`右转、`0x49`停车。当前命令已经解析并封装保存，四电机驱动尚未接入，因此不会在本工程直接驱动车轮。

底盘电机与陀螺仪遥测协议固定为：

| 字节 | 内容 | 当前值 |
|---|---|---|
| 0 | 包头1 | `0x55` |
| 1 | 包头2 | `0x52` |
| 2 | 左后电机速度 | `0x00`占位 |
| 3 | 左前电机速度 | `0x00`占位 |
| 4 | 右前电机速度 | `0x00`占位 |
| 5 | 右后电机速度 | `0x00`占位 |
| 6 | 陀螺仪角度 | `0x00`占位 |
| 7 | 包尾 | `0x5B` |

`Bluetooth_SetChassisTelemetry()`已经预留五个单字节原始字段更新接口。后续接入电机和陀螺仪时，应先确定速度正负方向、量程和角度0至360度的单字节映射规则，再由对应驱动层调用该接口更新数据。

实车确认左右方向原本正确，因此保持左侧90度和右侧270度不变，仅把前方扇区改为180度、后方扇区改为0度。

声光提示采用90厘米统一阈值：前方障碍物循环单响，后方障碍物优先循环双响；左侧障碍物绿灯快速闪烁，右侧障碍物蓝灯快速闪烁；左右均无近障碍物且雷达正常时红灯快速闪烁。红绿蓝快闪明暗半周期均为100毫秒，蜂鸣器由TIM2一毫秒中断驱动，不使用阻塞延时。

## 七、问题与解决

首次下载后进入 HardFault。异常栈返回地址被调试日志字符覆盖，根因是原 `Serial_Printf` 使用100字节栈缓冲区和无边界 `vsprintf`。现已改为256字节缓冲区、`vsnprintf`边界保护和强制结束符；重新烧录后CPU与串口持续运行正常。

首次声光版本使用TIM6作为毫秒时基，并把右侧蓝灯设为常亮。现已完全删除TIM6源码和Keil工程条目，复用原TIM2生成一毫秒时基；右侧蓝灯改为与左侧绿灯相同的100毫秒明暗半周期快速闪烁。
