# ESP32-C3 Super Mini 板载 LED 快闪测试

- 验证日期：2026-09-12
- 板型：ESP32-C3 Super Mini
- FQBN 等效配置：`esp32-c3-devkitm-1`
- 实测芯片：ESP32-C3 QFN32 revision v0.4
- Flash：4MB XMC
- USB 模式：USB-Serial/JTAG
- 串口：COM8，115200 bit/s
- 板载 LED：GPIO8，低电平点亮
- 快闪间隔：100 ms 翻转一次（完整亮灭周期 200 ms）
- RAM：13,900 / 327,680 字节（4.2%）
- 程序 Flash：245,196 / 1,310,720 字节（18.7%）
- 烧录速率：460800 bit/s
- 烧录校验：所有分区 Hash 校验通过
- 运行校验：串口持续输出每秒心跳，LED 翻转计数持续增长

串口验证节选：

```text
Running: 9275 ms, LED toggles: 90
Running: 10275 ms, LED toggles: 100
Running: 11275 ms, LED toggles: 110
Running: 12275 ms, LED toggles: 120
```

说明：旧版 RISC-V GCC 无法处理含中文的编译绝对路径，因此本机使用
`C:\ESP32C3_Build\ESP32C3_LED_FastBlink` 作为纯英文构建暂存目录；正式源代码仍保存在本工程目录。
