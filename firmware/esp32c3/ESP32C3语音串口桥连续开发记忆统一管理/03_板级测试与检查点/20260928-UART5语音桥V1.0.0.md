# UART5语音桥V1.0.0开发检查点

- 日期：2026-09-28（Asia/Shanghai）
- 目标：ESP32-C3接收STM32 UART5 TX的230400波特率十六进制数据，转换为115200后从GPIO21发送给语音模块。
- 参考基线：`1-3 ESP32C3_STM32_UART4_MQTT桥接`的GPIO20/GPIO21引脚分配，以及`1-1 ESP32C3_LED_FastBlink`的GPIO8低电平LED结论。

## 实现

- UART0：GPIO20 RX，230400-8-N-1，只接收。
- UART1：GPIO21 TX，115200-8-N-1，只发送。
- USB CDC：COM17，115200监视器配置，用于启动日志、十六进制预览和累计统计。
- 缓冲：UART RX 2048字节，软件环形队列4096字节。
- LED：接收数据后500ms内每80ms翻转；空闲时每秒短亮90ms。
- 数据：0x00至0xFF原样转发，不增加包头、包尾、CRC或换行。
