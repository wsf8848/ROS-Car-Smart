## 重要边界

- 一个UART不能同时配置RX 230400和TX 115200，本工程使用UART0与UART1分别完成波特率转换。
- 输入带宽约为输出两倍，只适合短小语音命令突发；持续满速输入最终必然溢出，必须通过日志确认`dropped=0`。
- STM32、ESP32-C3和语音模块必须共地；串口必须为3.3V TTL。
- 当前尚未连接STM32和语音模块，因此外部GPIO20输入、GPIO21输出的电气闭环需接线后验证；此项不能用烧录和启动日志替代。
