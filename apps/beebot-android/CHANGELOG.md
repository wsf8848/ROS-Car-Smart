# 更新日志 CHANGELOG

本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [2.6.3] - 2026-09-18

- 车辆主页改用萤石官方 EZOpenSDK 5.32 的 `EZPlayer` 和原生 `SurfaceView` 进行实时预览，不再把萤石画面交给 WebView。
- 播放器实现 Surface 解绑、页面暂停停止播放、离页释放和官方错误码回显；视频异常不会中断 MQTT、蓝牙、急停或车辆控制。
- 萤石 AppKey、AccessToken、设备序列号、通道号和设备验证码改从工程外 `ezviz-connection.env` 注入；AppSecret 不进入源码和 APK。
- 保留工具中心既有 HTTP、MJPEG、JPEG、RTSP 摄像头预览能力。

## [2.6.2] - 2026-09-17

### 修复
- MQTT 控制序号持久化到 App 私有配置，进程重启、覆盖安装或系统回收后继续单向递增，避免 ESP32 将重置序号误判为旧帧。
- ESP32-C3 允许通过完整校验且命令为安全停车 `0x49` 的帧重同步序号窗口；旧方向、模式和其他命令仍按原规则拒绝。

## [2.6.1] - 2026-09-17

### 修复
- 修复从 ASCII 目录联接构建时，Gradle 未解析真实工程路径而漏读外部 MQTT 配置，导致掌机显示“MQTT 配置缺失”的问题。
- MQTT 首次连接失败和掉线现在记录完整异常因果链，便于区分配置、网络、TLS 与认证故障；日志不包含 MQTT 凭据。

## [2.6.0] - 2026-09-17

### 新增
- 新增完全离线的关键词语音助手，不接入大模型或云端 API；Paraformer 完成分句后按关键词与同义词匹配固定业务意图。
- 支持查询掌机电量、充电状态、电池温度、时间日期、网络和 APP 版本，以及车辆在线、电量/电压、MQTT 业务延迟、四向雷达和车辆模式。
- 对话页逐轮显示“说话人：问题”和“小蜜蜂助手：回答”，保留原有 CAM++ 多角色档案、样本续录、人工标定和声纹管理。

### 安全与稳定性
- 车辆状态只读取现有 MQTT 与遥测新鲜数据；离线、缺失或超时会明确提示，不用默认值或旧值冒充实时状态。
- TTS 播报前停止 ASR，播报结束 350ms 后恢复；初始化失败、播报错误、被打断或待播报被覆盖时也会收敛回调，避免卡在回答状态或识别自身播报。
- 离开语音标签、关闭工具页或 App 进入后台时立即停止 ASR/声纹录音；保留 Composable 销毁兜底，避免退出动画期间重新拉起麦克风。

### 验证
- 固定意图、掌机/车辆消歧、雷达方向、车辆离线和遥测超时均有 JVM 单元测试覆盖。
- Debug/Release 单测、Release、lintVital 共 75 个任务通过；v2 签名、覆盖安装、Retroid 真机问答、真实状态和离页停录验收通过。

## [2.3.0] - 2026-09-12

- 主页新增两个独立切换按钮：通信方式在 WiFi模块/蓝牙间切换，车辆模式在手动/避障/自主间循环；三种车辆模式均支持 MQTT 或经典蓝牙下发。

### 修复
- 蓝牙自主模式不再被 100ms 摇杆中位 `0x49` 持续急停，自主导航可在 WiFi 与蓝牙两种通道下运行。
- STM32 自主决策现在服从 `0x49` 急停锁存，防止上锁或停车后下一决策周期重新驱动车轮。
- 三点工具入口移到左上车辆状态块右侧，消除与右侧解锁按钮的重叠。

### 验证

- WiFi 实链收到 `0x5C`、周期 `0x5E` 和关闭 `0x5F`；通过 Retroid `/dev/input/event4` 注入 R2，确认上锁阶段无 `0x6B`，解锁后同一输入连续下发 `0x6B`。
- 蓝牙切换后自动连接历史设备 `YesGood` 并进入智能小车页，手动与避障切换及遥测持续正常；自主实车行驶因安全原因未在无人看护状态启动。
- ESP32-C3 COM8 烧录各段 Hash 校验通过；STM32 V2.7 ARMCC 为 0 错误 0 警告，并经 Horco CMSIS-DAP 下载，pyOCD 比对 20,480 字节完全一致。
- APK 9,784,163 字节，SHA-256 `21EED8009741B140B65B437F3BE268896EDAE7C12735D634CEE380AD8239CF8C`，APK Signature Scheme v2 验证通过。

## [2.2.0] - 2026-09-12

### 新增
- 主控台模式改为 WiFi 远程与蓝牙控制双通道：WiFi 继续使用 MQTT 驱动实体摇杆、A 键停车和 L2/R2 调速；蓝牙自动连接最近成功设备并打开智能小车页。
- 蓝牙连接成功后智能小车页自动进入蓝牙控制，使用“先停车、再授权 0x5B”的四驱安全握手。

### 修复
- WiFi 车辆静止时每秒发送单次安全停车探测，持续刷新 ESP32 序号回执 RTT；超过 5 秒的旧延迟不再残留显示。
- 智能小车页在自动重连失败时直接显示具体蓝牙状态，便于回到蓝牙调试页处理配对。
- STM32 上电默认进入蓝牙手动模式，USART2 与 UART4 首个方向命令均可直接控制；0x5C/0x5D 避障和自主授权保持关闭，雷达只提供遥测。

### 验证
- Android 协议单元测试通过；Release 43 个任务（含 lint）通过，最终布局修正版覆盖安装到 Retroid `SN0004753`，冷启动、WiFi/蓝牙双向模式切换、蓝牙自动进入智能小车和无历史设备提示均通过，无本应用崩溃。
- 最终 APK 为 `9,780,767` 字节，SHA-256 `4DC3E4976ED331F99C0120610BA2E59A88E10BF50A7D3D249C5DBB3728F34988`；APK Signature Scheme v2 验证通过，1 个签名者。
- STM32 V2.6 ARMCC 全量编译 `0 Error(s), 0 Warning(s)`，程序大小 `Code=16042 RO-data=3138 RW-data=152 ZI-data=3984`。
- Horco CMSIS-DAP 可被系统和 pyOCD 枚举，但打开探针时仍超时；V2.6 尚未烧录，串口和架空车轮闭环待下载器物理恢复后完成。

## [2.1.0] - 2026-09-12

### 新增
- 按 ESP32-C3 已烧录固件实现 `55 43 01 seq cmd ... CRC8 5B` 原始 20 字节 MQTT 控制发布，QoS 0、Retain false，支持八方向、停车、模式和调速。
- 主控台实体摇杆以 20Hz 连续控制，回中、A 键、打开工具页与退出时主动停车；车辆首次上线先停车再授权当前模式。
- 解析 ESP32-C3 状态回执的控制计数、错误计数、最后序号/命令和 UART 帧数，并用序号回执计算业务链路 RTT。
- STM32 UART4 接收进入既有蓝牙控制状态机，共用命令白名单、四驱输出和 350ms 失联停车。

### 修复
- 四轮 `0x52` 遥测字段按 int8 二补码解析，HUD 单位改为真实的十毫秒编码器脉冲；模式优先显示车端遥测状态。
- 自主模式不再发送实体摇杆方向帧；解锁、上锁、鸣笛因无车端命令证据继续安全阻断。

### 验证
- 2 个协议单元测试通过，包含公网已验证停车帧 CRC 样本和八方向/死区映射；Release 43 个任务（含 lint）通过。
- STM32 本机未发现 Keil/ARMCC 工具链，代码尚待重新编译、烧录及架空车轮实测。

## [1.8.1] - 2026-07-26
