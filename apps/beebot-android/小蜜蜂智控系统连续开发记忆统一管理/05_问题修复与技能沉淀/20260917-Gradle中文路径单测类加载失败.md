# Gradle 中文路径单测类加载失败

## 现象

- `compileReleaseUnitTestKotlin` 成功，目标 `.class` 文件实际存在。
- `testReleaseUnitTest` 仍报告测试类 `ClassNotFoundException`。
- `--info` 输出中 Gradle Test Executor 的工程路径中文被显示为乱码。

## 失败判断

- 不是测试源码未编译，也不是 JUnit 缺失。
- 不是 sherpa-onnx 运行时错误；测试尚未进入测试方法。

## 根因

Windows 中文工程路径进入 Gradle Test Worker 的 classpath/参数文件后发生编码损坏，测试工作进程无法从乱码路径加载已经生成的测试类。

## 已验证解决方法

1. 为工程建立只指向原目录的 ASCII 路径目录联接，例如：
   `C:\Users\Bee\codex-work\BeeRobotController`。
2. 使用相同 Gradle/JDK，从该 ASCII 路径作为 `-p` 工程路径运行单元测试。
3. 本轮 `:app:testReleaseUnitTest --rerun-tasks` 24 个任务通过。

目录联接不复制、不覆盖工程文件；业务源码无需为此修改。Release 构建本身在原中文路径可以正常完成。
