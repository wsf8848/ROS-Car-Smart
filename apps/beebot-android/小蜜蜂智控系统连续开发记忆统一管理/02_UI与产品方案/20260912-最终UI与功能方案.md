## 产品定位

- 名称：小蜜蜂智控系统。
- 平台：Retroid Pocket 4 横屏掌机。
- 核心体验：打开 APP -> 登录/自动登录 -> 直接进入车辆摄像头第一视角主控台。

## 主控页面

### 背景与层级

- 车辆摄像头画面全屏铺底，是第一视觉层级。
- HUD 仅覆盖必要区域，避免遮挡驾驶中心视野。
- 默认保留中心轻量准星、底部链路状态和视频帧率信息。

### 顶部状态

- 左上显示小蜜蜂智控系统、车辆编号和视频 LIVE 状态。
- 右上显示车辆在线/离线、MQTT 延迟和三点菜单。
- 车辆在线不能只依赖 APP 与 Broker 的连接；应优先依据 `car/001/status`、Last Will 和遥测新鲜度综合判断。
- 延迟应测量业务链路或心跳 RTT，不能把手机 Wi-Fi 网关 ping 冒充 MQTT 车辆延迟。

### 中上遥测胶囊

一行悬浮胶囊显示：

- 电量百分比与电压。
- 左前、右前、左后、右后四轮速度，单位明确。
- Pitch、Roll、Yaw 欧拉角，统一角度单位。
- 激光雷达前、后、左、右最近距离，统一厘米单位。
- 当前控制模式：手动、避障、自主。

遥测超时必须显示无数据/失效状态，禁止继续展示旧值造成误判。

### 右侧控制区

自上而下固定为：

1. 解锁。
2. 上锁。
3. 鸣笛。
4. 停车。
5. 模式切换。

交互要求：

- 模式循环：手动 -> 避障 -> 自主 -> 手动。
- 模式按钮同时显示当前模式或下一模式，避免盲切。
- 停车使用红色危险语义、加强震动和明确语音。
- 解锁、上锁属于安全敏感动作，代码实现阶段应加入防误触策略；具体采用长按或二次确认需在正式实现前结合实体按键确定。
- 每个操作都提供视觉反馈、震动反馈和中文语音提示，并避免同一入口重复播报。

## 三点菜单

采用右侧抽屉/工具中心，保留以下入口：

- 掌机输入监视：原默认主页迁入此处。
- 蓝牙调试。
- 智能小车。
- 阿克曼小车。
- ROS 网页。
- 系统设置。

旧蓝牙控制功能继续可用，与 MQTT 新主线并存；不得在本轮重构时删除。

## 设置页

- MQTT 连接和车辆编号状态。
- 摄像头自动播放/重连。
- 语音提示开关。
- 震动反馈开关。
- 屏幕常亮与摇杆死区。
- 软件版本号、适配设备、开发者信息。
- 退出登录。

## 语音方案

- 每次真正进入主控页面播放：`欢迎使用小蜜蜂智控系统，开始您的驾驶吧!`
- 自动登录与手动登录只能触发一次欢迎语，避免重组或页面恢复重复播报。
- 解锁、上锁、鸣笛、停车和模式切换分别播报对应结果。
- 语音应在动作入口统一触发，软件按钮与实体按键复用同一控制函数。
