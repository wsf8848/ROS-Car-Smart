# 2026-09-18 萤石 C2C 车辆主页实时预览接入

## 任务目标

- 将萤石 CS-C2C-1D1WFR 接入“小蜜蜂智控系统”车辆 WiFi 控制主页，作为实时画面背景/预览。
- 按用户指定使用萤石开放平台 Android SDK，不使用摄像头 RTSP。
- 保留现有 MQTT、蓝牙、遥测、急停、上锁和语音能力，视频断流不得影响控制链路。

- 现有独立 `CameraStreamScreen`、RTSP/HTTP/MJPEG 工具页继续保留，除非后续用户明确要求删除。

## 检查点 2：萤石官方 SDK 文档核验

- 状态：已完成并以当前官方资料修正（2026-09-18）。
- 官方旧 `EZUIKit-Android` GitHub 仓库最后更新于 2018-03-22，只能作为历史示例，不能作为本项目正式接入基线。
- 当前官方下载页提供 Android `EZOpenSDK v5.32`（更新于 2026-09-15），Maven 坐标为 `io.github.ezviz-open:ezviz-sdk:5.32`；SDK 4.19.0 之后还需显式依赖 `okhttp:3.12.1` 与 `gson:2.8.5`。
- 官方 v5.32 AAR 已实际下载并检查，包含 `arm64-v8a` 和 `armeabi-v7a` 原生库；当前工程仅打包 `arm64-v8a`，与 Retroid Pocket 4 相符。
- 当前官方国内初始化：`EZOpenSDK.initLib(application, appKey)`；授权：`EzvizApplication.getOpenSDK().setAccessToken(accessToken)`。发布版必须关闭 SDK 日志和码流调试缓存。
- 当前官方直播流程：`createPlayer(deviceSerial, cameraNo)` -> `setHandler(handler)` -> `setSurfaceHold(surfaceHolder)` -> 如设备开启加密则 `setPlayVerifyCode(verifyCode)` -> `startRealPlay()`。
- 生命周期：离页调用 `stopRealPlay()`，销毁调用 `release()`，`surfaceDestroyed` 必须额外 `setSurfaceHold(null)`，否则下一次取流可能报窗口占用错误 `321022/322008`。
- 播放结果使用 SDK 自带的 `EZRealPlayConstants.MSG_REALPLAY_PLAY_SUCCESS/FAIL`；失败错误码从 `ErrorInfo msg.obj` 获取。Token 过期应由 App 向自有服务刷新后重新设置，不能把 AppSecret 放入 APK。
- 官方资料确认 Android SDK 最低 Android 5.0、JDK 17；本工程 minSdk 24、JDK 17 满足运行和构建下限。官方 Demo 使用 JDK 21/AGP 8.5.2 是其示例开发环境，不等同于本工程必须升级；需以本工程 AGP 8.1.1/JDK 17 实际编译验证为准。
- 官方页面：`https://open.ys7.com/help/4177`（Android 接入）、`https://open.ys7.com/help/4151`（初始化授权）、`https://open.ys7.com/help/4152`（直播预览）、`https://open.ys7.com/cn/s/download`（SDK 下载）。
- AppKey 约束：官方开源 App 示例要求在 `EZOpenApplication` 中填入申请的 AppKey，并把 Android `applicationId` 改成与 AppKey 绑定的包名；本 App 包名固定为 `com.fyx.beebot`，申请时必须绑定该包名。
- 不在源码、记忆或日志写入 AppKey、AppSecret、AccessToken 或个人账号信息。

## 检查点 4：拟定工程接入边界

- 状态：方案已确定，等待用户资料与 UI 确认后实施。
- Gradle 增加 `io.github.ezviz-open:ezviz-sdk:5.32`、`okhttp:3.12.1`、`gson:2.8.5`，保留工程现有 `arm64-v8a` 过滤。
- 新增独立萤石预览封装，负责 SDK 单次初始化、播放器创建、Surface 绑定、播放消息、停止、释放和 Token 失效状态，不把萤石生命周期散落到车辆控制逻辑中。
- 主页面仅消费预览状态；萤石断流、Token 过期或设备离线都不得停止 MQTT/蓝牙控制，也不得阻断急停。
- AppKey、AccessToken、设备序列号、通道号和设备验证码均从工程外受控配置注入；AppSecret 只允许留在自有服务器，绝不进入 APK。
- 第一阶段可使用 AccessToken 快速验证，正式发布建议由自有服务器保存 AppSecret、刷新 AccessToken，并通过已授权接口下发短期凭据；不得在客户端调用携带 AppSecret 的 Token 获取接口。
