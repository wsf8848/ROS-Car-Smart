- 第二次失败根因：旧 Skill 遗留的非标准元数据字段；与本轮正文内容无关。
- 第二次处理方法：删除无功能用途的 `agent_created` 字段，保留 `name` 与 `description`，然后重新校验。

- 第一次扫描结论：误报。上述都是接入说明中允许公开记录的服务器地址或主题，不是账号、密码、密钥或证书秘密；扫描器错误地把 env 中所有值都按秘密处理。
- 调整方法：只扫描键名包含 `PASSWORD`、`USERNAME`、`SECRET`、`TOKEN`、`PRIVATE`、`CERT`、`KEY` 的敏感配置，且只报告键名不输出值。
- 第二次扫描失败：PowerShell 在执行键名正则时覆盖了自动变量 `$Matches`，导致随后访问原 env 匹配组为空并产生 `null-valued expression`；末尾“未发现”输出无效，不能作为通过证据。
- 第二次修正：匹配 env 行后立即把键和值保存到独立变量，再检查键名类型，避免复用 `$Matches`。
- Git 范围：新记忆目录是本轮新增；工程其余修改和旧记忆目录均为本轮之前已有，未被本轮更改或回退。
