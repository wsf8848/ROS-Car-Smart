# 2026-09-12 v2.0.0 正式开发与真机验证

## 任务目标

按用户已经确认的最终 UI 方案，在现有 BeeRobotController v1.9.5 工作区上增量实现“小蜜蜂智控系统”v2.0.0，并利用已连接的 Retroid Pocket 4 完成编译、安装、启动、页面和实体输入验证。

## 本轮范围

1. 审计并验证现有 v1.9.5 脏工作区基线，不覆盖历史改动。
2. APP 名称、登录密码、登录动画、自动登录和欢迎语升级。
3. 摄像头全屏主控页面、遥测胶囊、车辆在线/MQTT 延迟、右侧控制按钮。
4. 原掌机输入监视页迁入三点菜单，旧蓝牙/智能小车/阿克曼/ROS/摄像头/设置全部保留。
5. 实现 MQTT 安全连接层、状态/遥测订阅和控制发布；不编造未确认的车辆 20 字节字段协议。
6. 更新版本、README、CHANGELOG、APK 与连续开发记忆。
7. 在已连接掌机完成安装、启动、截图、登录与实体按键验证。

## 明确边界

- 当前控制帧仅确认固定 20 字节，字段含义尚未最终定稿；在获得 STM32/ESP8266 协议证据前，不把示例结构作为正式车辆控制协议。
- 解锁、上锁、鸣笛、姿态遥测字段尚无车端协议依据；UI 和统一动作入口可先完成，真实下发必须保持“协议待定/安全阻断”。
- 本轮若车载 ESP8266 尚未烧录或未接入车辆，不能声称完成 APP 到真车的端到端控制验证。
- MQTT 密钥只能从受控 env 注入构建，不写入 Git 跟踪源码、记忆、README 或 Skill。
