# 2026-09-12 主页车辆模式、锁定与鸣笛闭环

## 任务目标

- 主页模式按钮支持手动、避障、自主循环，并真正控制 STM32 对应模式。
- 点击上锁后立即停车，并禁止摇杆、实体按键、调速与模式控制发布到 MQTT；点击解锁后恢复下发。
- 鸣笛按钮采用状态切换：首次点击开启非阻塞连续间歇滴滴，再次点击关闭。
- 修改并验证 APP、ESP32-C3、STM32 全链路；STM32 仅使用 Horco CMSIS-DAP 下载。

## 已确认语义与安全边界

- 用户于 2026-09-12 明确确认：上锁禁止遥控器指令下发到服务器，解锁允许。
- 用户明确要求本次不画 UI 草图，直接在现有主页五按钮布局上实现。
- 模式循环按既有产品方案：手动 -> 避障 -> 自主 -> 手动；切换前先停车。
- 保留 ESP32-C3 300 ms 与 STM32 350 ms 运动失联停车保护。
- 蜂鸣采用非阻塞定时状态机，不允许阻塞电机、雷达、遥测或串口处理。
- 用户追加确认主页必须拆成两个按钮：通信方式为 WiFi模块/蓝牙；车辆模式为手动/避障/自主，三种车辆模式在两种通信方式下都能生效。
