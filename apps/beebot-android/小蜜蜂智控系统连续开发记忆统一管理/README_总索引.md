## 强制执行规则

1. 开始任何新任务前，先在 `00_当前开发任务` 新建任务记忆，并在本索引登记为“进行中”。
2. 每完成一个检查点，立即写入完成时间、改动、验证证据、未验证边界和下一步。
3. 遇到问题时先记录现象与失败方案；定位后补根因；修复后补验证结果，不允许只记录最终答案。
4. 编译成功不等于功能验证成功；安装、启动、页面、输入、网络和实车结果必须分开记录。
5. 只有全部要求验证无误后，才更新 README/CHANGELOG、版本、APK、Git 提交和标签。
6. 每个可复用问题解决后，同步完善 `C:\Users\Bee\.codex\skills\xiaomifeng-robot-controller\SKILL.md`；只沉淀可复用规则，不堆积一次性日志。
7. 本目录不得保存 MQTT 账号密码、签名密码、证书私钥等服务器秘密；敏感 MQTT 参数继续只保存在项目外层受控文件 `1-0 服务器接入说明\mqtt-connection.env`。
