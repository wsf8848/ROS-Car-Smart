# 2026-09-26 LD14厂家ROS示例错误声明30米量程

## 现象

- 自动质量报告读取真实`/scan`发现`range_max=30m`，静态环境中甚至出现13.527m有效回波。
- 该值来自厂家ROS2示例`main.cpp`，不是LD14数据手册规格。

## 权威依据

- 随设备提供的`LD14激光雷达数据手册.pdf`第4页明确：测距范围0.15~8m，条件为80%目标反射率；典型扫描频率6Hz。
- 因此8m以外回波属于超规格数据，不应送入SLAM、Nav2代价地图或网页障碍距离判断。

## 修复

- 驱动`LaserScan.range_max`从30.0改为8.0。
- 有效范围判断从`<=min / >=max`改为`<min / >max`，保留等于0.15m和8m的合法边界值。
- 在板端使用CMake clean构建，明确安装新二进制；安装/正式运行文件SHA-256为`5f20fb5a706229826b065387d22108e643ac3341dc04cce91efd8fb9e515c5cf`。

## 回归

- 连续20秒121帧，频率5.996Hz，角度覆盖359.46°，无长间隔。
- 消息契约为0.15~8m，实际最大有效回波3.53m，范围违规0。

## 规则

- 传感器ROS示例中的`range_min/range_max`不能直接当产品规格，必须对照随设备数据手册。
- 超规格回波必须在驱动层过滤，不能仅在网页层隐藏，否则仍会污染SLAM和代价地图。
