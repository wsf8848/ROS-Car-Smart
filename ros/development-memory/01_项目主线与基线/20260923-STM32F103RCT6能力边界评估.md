# 2026-09-23 STM32F103RCT6 能力边界评估

## 结论

STM32F103RCT6 足够完成本项目全部底层实时控制和 ROS 底盘接口功能，但不运行“所有 ROS 功能”。ROS2、SLAM、AMCL、Nav2、地图、路径规划、避障决策和巡逻任务运行在 RDK X5。

正确架构是：

```text
RDK X5：ROS2 / SLAM / 定位 / Nav2 / 路径规划 / 巡逻
                     ↓ UART5连续速度和控制状态
STM32F103RCT6：协议 / 控制权 / 编码器 / ICM42670 / 四轮PID / PWM / 安全停车
```

## F103负责且能力足够的任务

- 四路正交编码器计数；
- 四轮速度PID和差速速度解算；
- 电机方向与PWM输出；
- ICM42670三轴加速度、三轴角速度和温度采集；
- LD14本地近障数据解析与安全停车；
- USART2蓝牙、UART4 ESP32-C3/MQTT、UART5 RDK ROS通信；
- 三控制源仲裁、心跳、CRC、序号和超时；
- 电池、底盘状态和安全故障上报；
- 急停、失联、倾倒、堵转及本地保护。

## 不放到F103上的任务

- ROS2中间件和完整ROS节点图；
- `slam_toolbox`、AMCL、Nav2；
- 地图与代价地图；
- 全局和局部路径规划；
- `robot_localization` EKF融合；
- 多航点巡逻任务管理；
- 视觉识别或复杂激光算法。

## 资源证据

- 芯片基线：72MHz Cortex-M3、256KB Flash、48KB SRAM、无硬件FPU。
- 当前工程 `1-28` 的 `Listings/Project.map`：Total ROM Size 21.05KB，Total RW Size 4.68KB。
- 当前工程 `Objects/Project.build_log.htm`：Code 18,218B、RO-data 3,138B、RW-data 196B、ZI-data 4,596B，0 Error、0 Warning。
- 静态Flash和RAM余量充足，后续新增ICM42670、正式协议和PID不会仅因容量迫使换MCU。

## 尚需实测的边界

静态容量充足不代表实时性已经通过。合入全部功能后必须测量：

- 100Hz或目标控制周期的最坏执行时间与抖动；
- USART1/2、UART4/5同时工作时的丢帧和缓冲峰值；
- 四编码器高速计数及溢出处理；
- ICM42670采样频率、时间戳和软件I2C占用；
- LD14 230400波特率解析是否阻塞控制环；
- RAM栈峰值、环形缓冲和协议队列余量；
- 车轮架空与低速落地时四轮PID稳定性。

仅当真实证据表明CPU持续超时、控制抖动无法接受、RAM不足或外设资源冲突无法解决时，才评估升级到STM32F4/G4/H7等平台。
