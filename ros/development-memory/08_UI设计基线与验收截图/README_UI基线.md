## 强制要求

后续接入RDK X5、ROS2、Nav2和实体传感器数据时，必须以本截图为1:1视觉开发基线：顶部集中连接、安全与车辆状态；地图为最大主区域；右侧依次集中任务控制、控制源、人工接管和巡逻任务；急停仍位于顶部危险操作区。功能接入只替换模拟数据源，不得擅自推翻或重做UI。

地图以真实占据栅格为主视觉，逐格呈现SLAM/地图数据：绿色格表示可通行，红色格表示占据障碍，深灰格表示未知；全局规划路线使用高亮绿色格/路径覆盖，局部运行轨迹、LD14扫描、车辆位置朝向、蓝色当前标定/目标点、巡逻航点、障碍和代价地图、已行驶轨迹作为叠加层，并支持独立显隐。最终栅格交互基准截图SHA-256：`A5DF00D073F22FBE24EC912777DCD907876921561AB3B82557E8FE17F0611DD0`。

地图任意位置支持左键快速选点并显示蓝色标记；右键在鼠标位置弹出操作菜单，至少包含“标定此点”和“导航到此点”。坐标必须由屏幕位置按当前 OccupancyGrid 原点、分辨率和地图坐标变换换算，禁止在正式实现中使用固定比例假坐标。导航动作需要受控网关二次校验、状态提示和用户确认策略；未接ROS前只能做本地UI演示，不能发送车辆运动命令。

“1:1”指视觉结构、信息层级、色彩和图层语义与本基线一致；真实地图几何、路径形状、障碍位置、坐标和数值必须来自ROS2实体数据，不得硬编码成截图内容。
