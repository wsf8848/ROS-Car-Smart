# 2026-09-23 RDK X5 四驱自主导航项目立项与记忆机制

## 一、任务目标

1. 为 RDK X5 ROS 自主导航项目建立独立、统一、可持续恢复的开发记忆。
2. 保存本轮确认的四驱自主避障、建图、导航和巡逻总体方案。

## 二、用户确认的目标

- 计算平台：D-Robotics RDK X5，运行 RDK OS / ROS2 / TogetheROS.Bot。
- 实时底盘：STM32F103RCT6 一体板，驱动四轮电机和四路编码器。
- 环境感知：LD14 二维激光雷达，完整串口扫描数据接入 RDK，同时保留 STM32 本地紧急避障能力。
- 惯性传感器：STM32 板载 ICM42670，由 STM32 采集后通过底盘链路送入 ROS。
- 功能目标：手动遥控、辅助避障、二维建图、定位、定点导航、多航点巡逻、人工接管和失联安全停车。
