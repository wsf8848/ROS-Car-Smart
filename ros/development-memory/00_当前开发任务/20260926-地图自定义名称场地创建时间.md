# 地图自定义名称、场地与创建时间

## 目标

为 Bee ROS Web Console 的地图管理增加任务地图自定义名称、场地和创建时间，并确保保存后可在 RDK X5 板端长期加载和显示。

## CP0 基线审计

- 工程：`1-5 地瓜派板子ROS/Bee ROS Web Console`。
- 地图正式目录：`/opt/bee-ros-web-console/data/maps`。
- 服务：`bee-web-console.service`，HTTP 8080，认证已启用。
- 保护边界：不修改蓝牙、MQTT、STM32工程；不开放运动能力；不改变 ROS 标准 YAML/PGM 格式。

## CP1 代码实现

- 网关 `gateway/bee_gateway.py`：保存动作接收严格的 `action/name/site` 字段；名称和场地必须为非空字符串，去除首尾空白，最大 80 字符，拒绝控制字符。
- 每张地图新增同名 JSON 侧车：`<map_id>.json`，记录 `id/name/site/created_at/format`。
- `/api/maps` 返回 `name/site/created_at`；无 JSON 的旧地图回退到地图 ID、`未填写场地` 和 YAML 修改时间。
- 前端地图管理弹窗增加“任务地图名字”和“场地”输入框，列表显示名称、场地、创建时间、文件大小和 YAML/PGM 完整性。
- ROS 标准 `.yaml/.pgm` 保持不变，地图数据仍只保存于板端固定目录。

## CP4 接口验收

- 使用同源 Origin 登录成功：HTTP 200。
- `/api/maps` 返回 HTTP 200，现有 3 张旧地图均包含 `name/site/created_at`，且 `complete=true`。
- 非法保存验证：空名称返回 409 `invalid_map_name`；空场地返回 409 `invalid_map_site`；额外字段返回 400 `unsupported_action`。
