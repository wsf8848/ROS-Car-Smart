# 2026-09-26 Windows网页语音提示功能

## 目标与边界

- 仅在Windows浏览器端增加语音提示，不改RDK、ROS2、LD14、STM32和掌机链路。
- 页面提供明确的“语音提示”开关，默认关闭并记住用户选择；关闭时不调用浏览器播报。
- 打开后播报必要操作和关键状态变化：语音开启/关闭、网页与雷达连接/断开/恢复、地图接收、地图/LD14主视图切换、雷达超时、板卡重启/关机请求、导航/巡逻等操作反馈。
- 不对每一帧LaserScan播报，避免6Hz持续播报造成噪声；使用去重、冷却和有限队列。
- 浏览器不支持`SpeechSynthesis`时，显示不可用状态且不影响页面其他功能。

## 检查点1：基线审计

- 时间：2026-09-26（Asia/Shanghai）。
- 当前Bee ROS Web Console已在RDK X5 `192.168.127.10:8080`运行，前端静态文件位于`/opt/bee-ros-web-console/frontend`；顶部有状态栏、模式、重启/关机和急停按钮，但没有语音控制。
- 浏览器端最合适的实现是原生Web Speech API `window.speechSynthesis`，无需联网和板端服务，符合Windows电脑优先和热点离线要求。
- 保护边界：不播报真实每帧点云；关机/重启仍需原确认流程，语音只提示即将执行/请求结果，不代替确认；急停、导航和巡逻未接入时仍保持禁用。
- 状态：进行中。

## 检查点2：本地语音功能实现与构建

- 时间：2026-09-26（Asia/Shanghai）。
- 顶部状态栏新增“语音关闭/语音开启”按钮，使用浏览器原生`SpeechSynthesis`，默认关闭；用户选择写入`localStorage`，同一Windows浏览器后续访问会恢复选择。
- 中文播报参数固定为`zh-CN`、语速0.96、音量0.9，并优先选择Windows浏览器返回的中文语音；浏览器不支持时按钮显示“语音不可用”，不影响其他功能。
- 已接入关键事件：语音开关、地图/LD14主视图切换、地图首次接收、地图选点、网关连接/断开、LD14首次在线/恢复/超时、电源操作确认与请求结果，以及未来启用的导航、巡逻、人工接管、方向控制和急停按钮。

- 验证：`node --check frontend/live.js`通过；`tools/build-frontend.ps1`成功重建`frontend/index.html`；正式产物包含语音按钮、样式和所有关键事件播报标记。
