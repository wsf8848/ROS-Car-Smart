# 2026-09-25 LD14与栅格地图主视图切换及悬停保持

## 目标与边界

- 默认保持栅格地图为主区域，LD14为右下角独立小窗。
- 点击“LD14扫描”后，LD14占满与栅格地图相同的主区域，并提供“最小化”按钮恢复地图主视图和右下角雷达小窗。
- 点击“栅格地图”同样恢复地图主视图。
- 鼠标持续停在真实回波附近时，提示跨越后续扫描帧持续显示并更新；仅在移开、附近已无回波或数据超时/断开时隐藏。
- 不改变地图坐标换算、系统关机/重启、任务控制和安全边界。

## 检查点1：基线审计

- 时间：2026-09-25（Asia/Shanghai）。
- 当前默认状态为真实`/map`栅格占满主区域，真实LD14以右下角250×150小窗显示；“栅格地图”和“LD14扫描”按钮仅沿用旧图层显隐逻辑，没有主视图切换语义。
- 当前每约6Hz到达一帧`/scan`时都会清空回波后无条件调用`hideRadarTooltip()`，导致鼠标未移动时提示也会一闪而过。
- 修复设计：由前端维护`radarExpanded`主视图状态，并在捕获阶段接管grid/scan按钮；雷达大画面提供独立最小化按钮。维护最近鼠标屏幕坐标与是否仍在雷达区域，新帧完成后重新用`getScreenCTM()`做12px最近点命中，持续刷新同一位置的真实回波数据。
- 保护边界：雷达超时、断链和鼠标离开仍立即清除提示；无`map→laser` TF，LD14继续明确标注“独立扫描·未配准”。
- 状态：进行中。
