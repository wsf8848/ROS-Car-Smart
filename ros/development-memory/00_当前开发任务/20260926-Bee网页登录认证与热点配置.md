# Bee网页登录认证与热点配置

## 任务目标

- 为 Bee ROS Web Console 增加服务端登录认证与独立登录页。
- 登录页采用专业控制台视觉与克制动画，支持“下次自动登录”。
- 控制台、业务 API、WebSocket 实时数据与高风险操作全部要求有效会话。
- RDK X5 热点名称按用户指定值配置；热点密码与管理员密码只在板端受限配置中注入。

## 安全边界

- 不在源码、前端、Git、日志、开发记忆或 Skill 中记录真实热点密码、管理员密码、会话令牌。
- 密码只保存为 PBKDF2-SHA256 加盐哈希；浏览器只持有 HttpOnly、SameSite=Strict 会话 Cookie。
- HTTP 热点阶段默认不设置 Secure Cookie；迁移 HTTPS 后通过环境变量启用 Secure。
- 登录改造不得解除任务 API 的 fail-closed 状态，不得改动蓝牙、MQTT 或 STM32 控制语义。
