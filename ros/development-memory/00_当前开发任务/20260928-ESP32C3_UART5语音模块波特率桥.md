# ESP32-C3 UART5语音模块波特率桥

- 日期：2026-09-28（Asia/Shanghai）
- 状态：固件已编译、烧录、启动日志验证；STM32与语音模块外部电气闭环待硬件接入。

## 目标链路

```text
STM32F103 UART5_TX / 230400
  -> ESP32-C3 GPIO20 / UART0_RX
  -> 4096字节透明二进制缓冲
  -> ESP32-C3 GPIO21 / UART1_TX / 115200
  -> 语音模块RX
```

## 完成内容

- 独立工程：`C:/Users/Bee/Desktop/远程车控制系统/1-3 ESP32C3工程代码/1-4 ESP32C3_UART5_VoiceBridge`。
- 沿用已验证MQTT桥接引脚：GPIO20输入、GPIO21输出、GPIO8板载低电平LED。
- 两个硬件UART分别设置230400和115200；USB CDC保留下载与调试，避免同一UART无法使用不同RX/TX波特率的问题。
- 0x00至0xFF原样转发，不增加或删除任何协议字节。
- LED：接收数据后500ms内每80ms翻转；空闲每秒短闪一次。
- 缓冲：2048字节UART RX缓冲、4096字节软件环形队列；USB日志提供突发十六进制预览和`rx/tx/dropped/queued`统计。

## 安全与后续

- 三方必须共地，且使用3.3V TTL；语音模块不是3.3V兼容时必须加电平转换。
- 230400输入带宽高于115200输出，只适合短小语音指令突发，STM32不得持续满速发送长流；正式联调必须确保`dropped=0`。
- 当前没有STM32和语音模块接入本ESP32-C3，因此尚未把GPIO20到GPIO21的真实波形、字节一致性和语音播报标记为硬件通过。
- 接线后使用USB-TTL或逻辑分析仪在GPIO21按115200抓取已知命令，逐字节比对，再连接语音模块验证播报。
