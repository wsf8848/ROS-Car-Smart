# 2026-09-23 三控制链路功能范围冻结与实施顺序

## 一、用户确认的最终目标

最终构建一辆同时支持以下三条控制链路的四驱车辆：

1. 掌机蓝牙控制；
2. 掌机 MQTT 控制；
3. 新增 RDK X5 ROS 控制。

原有蓝牙、MQTT控制、STM32避障和原自主模式保持原功能与兼容性，不删除、不重写、不改变原有操作方式。新增 ROS 控制必须实现四项核心能力：

- 自主导航；
- 导航避障；
- 全局/局部路径规划；
- 定点与多航点巡逻。

## 二、不可破坏的兼容边界

- 掌机蓝牙 -> 蓝牙模块 -> STM32 USART2 链路保留。
- 掌机 -> MQTT -> ESP32-C3 -> STM32 UART4 链路保留。
- STM32 原有本地近障保护、避障模式、原自主模式和控制超时停车保留。
- 新增 RDK X5 -> STM32 UART5 ROS 链路，不通过改坏旧协议实现。
- 旧链路仍使用其现有命令；ROS 使用带版本、长度、类型、序号、时间戳和 CRC 的正式协议以及连续 `linear.x/angular.z`。
- 三个控制源必须互斥。优先级：硬件急停 > STM32安全保护 > 人工蓝牙/MQTT > ROS自主。
- 蓝牙与 MQTT 之间的既有优先级需通过源码和实车审计确认，在此之前不得重定义。
- 原 STM32 自主模式与 ROS 地图自主导航必须使用不同模式标识和状态回报。

## 三、严格实施顺序与阶段门

### 阶段0：冻结并回归原功能

- 审计当前 STM32、ESP32-C3、掌机源码和版本状态。
- 分别验证蓝牙前后左右/停止/调速、MQTT远程控制、原避障/自主模式及失联停车。
- 保存串口日志、视频或实车结果作为后续每阶段回归基线。
- 阶段门：旧功能未取得证据，不进入协议开发。

### 阶段1：正式协议与控制权设计

- 定义 UART5 正式帧、连续速度、轮速、IMU、电池、底盘状态、心跳、序号、时间戳和 CRC。
- 定义三控制源状态机、抢占、切换、超时和零速度过渡。
- 阶段门：协议文档评审完成、收发示例和异常行为明确。

### 阶段2：STM32 增量开发

- 从 `1-28 UART5接入鲁班猫ROS底盘协议` 复制派生新版本，不覆盖旧目录。
- 合入板载 ICM42670、四轮连续速度目标和速度闭环、UART5正式协议及控制源仲裁。
- 每完成一项立即回归 USART2蓝牙、UART4 MQTT、原避障/自主模式。
- 阶段门：编译、烧录、传感器、车轮架空、低速落地和旧功能回归分别有证据。

### 阶段3：RDK底盘驱动与板对板通信

- 实现 `bee_base_driver`，完成 `/cmd_vel` 下发和轮速、IMU、电池、状态发布。
- 验证 CRC、序号、频率、丢帧、超时停车、人工抢占和模式切换。
- 阶段门：ROS 尚未导航时，底盘收发和安全行为已独立稳定。

### 阶段4：LD14与整车标定

- RDK取得 LD14完整360度数据并发布 `/scan`，STM32继续保留本地近障保护。
- 实测轮径、轮距、编码器每圈计数、四轮方向、PID、IMU零偏/轴向及雷达安装位姿。
- 阶段门：传感器单位、坐标、时间戳、频率和TF全部正确。

### 阶段5：连续里程计

- 四轮编码器与ICM42670通过 `robot_localization` 融合。
- 验证固定距离直线、固定角度旋转和闭合轨迹误差。
- 阶段门：里程计连续、方向正确、误差达到实车可用范围。

### 阶段6：SLAM建图

- 用保留的蓝牙或MQTT人工低速驾驶完成建图。
- 验证地图比例、墙体重影、回环和保存/重载。
- 阶段门：地图质量满足定位和路径规划。

### 阶段7：定位与路径规划

- 打通地图加载、AMCL、全局规划器、局部控制器和代价地图。
- 先验证只规划不动车，再车轮架空、低速落地验证。
- 阶段门：路径合理、TF稳定、控制输出限速有效。

### 阶段8：ROS自主导航与避障

- 从空旷单点导航开始，再验证静态障碍、动态障碍、窄通道和恢复行为。
- 验证本地安全保护、急停、ROS失联和蓝牙/MQTT人工接管。
- 阶段门：到点、避障、恢复和安全接管全部通过。

### 阶段9：定点与多航点巡逻

- 实现单点、多点、循环巡逻、失败重试、暂停/恢复和低电量处理。
- 连续多轮运行并记录到点误差、失败率和恢复结果。
- 阶段门：巡逻及异常恢复达到可交付状态。

### 阶段10：掌机ROS功能整合

- 在旧蓝牙/MQTT控制不变的前提下，最后新增ROS模式入口、地图、路径、目标点和巡逻状态。
- 涉及新页面先出UI草图确认，再修改Android工程。
- 阶段门：三条控制链路均通过完整回归，互斥与人工接管正确。
