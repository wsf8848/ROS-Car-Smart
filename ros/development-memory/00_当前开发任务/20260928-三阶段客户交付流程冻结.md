# Bee ROS小车三阶段客户交付流程冻结

- 日期：2026-09-28（Asia/Shanghai）
- 状态：用户已确认，作为车辆到货后的主开发顺序与最终交付验收范围。
- 核心原则：严格按第一步建图、第二步单点导航、第三步巡逻任务推进；上一阶段未通过实车验收，不进入下一阶段。现有蓝牙、MQTT、STM32避障和安全保护不得被破坏。

## 第一阶段：人工遥控建图、命名、保存与加载

### 用户操作流程

1. Windows笔记本连接小车热点并打开Bee ROS Web Console。
2. 选择“新建地图/开始建图”。
3. 使用人工遥控让小车低速走完整个场地，使LD14扫描覆盖可通行区域、墙体、障碍和主要通道。
4. 回到起始区域形成闭环，检查地图墙体是否重合、比例是否正确、是否存在明显漂移和重影。
5. 输入自定义地图名称和场地名称，保存地图。
6. 停止建图后从地图列表重新加载该地图；重启网站或板卡后仍能找到并加载。

### 保存内容

- ROS标准地图：同名`.yaml + .pgm`。
- Bee元数据：同名`.json`，包含地图ID、自定义名称、场地、创建时间和格式。
- 固定保存位置：RDK X5板端`/opt/bee-ros-web-console/data/maps`。

### 第一阶段通过标准

- 地图覆盖客户要求的完整可运行区域。
- 可通行区域、障碍和未知区域显示正确，地图尺度和方向正确。
- 自定义地图名称、场地和创建时间正确显示。
- 保存、列表刷新、加载、卸载和重启后恢复均成功。
- 加载地图后小车能够完成有效定位；未定位成功时禁止进入导航。

## 第二阶段：地图任意点单点导航

### 用户操作流程

1. 从地图列表加载第一阶段保存的地图。
2. 确认小车定位有效、LD14在线、底盘在线、IMU/里程计正常、Nav2可用。
3. 在实时地图上点击任意合法可通行点。
4. 右键选择“导航到此点”。
5. 通过箭头设置或显示目标朝向；箭头代表到达目标点后的最终车头方向。
6. 网站显示目标点、全局规划路径、局部运行轨迹、当前位置、当前朝向和导航状态。
7. 小车自主规划、避开实时障碍，到达目标位置并自动停车。

### 第二阶段通过标准

- 不能向红色障碍格、深灰未知区或地图边界外发送目标。
- 右键导航请求必须经Bee受控网关和Nav2 Action下发，不能由浏览器直接驱动电机。
- 箭头朝向转换为目标Pose的yaw，车辆到点后位置和朝向进入配置容差。
- 到点后`cmd_vel`归零，STM32电机停止，网页明确显示“导航成功”。
- 无可行路径、定位丢失、障碍阻塞、通信失联、人工接管、取消和急停均能安全停止并显示失败原因。
- 至少在场地内选择多个远近不同的合法点重复验证，不以单次成功作为交付完成。

## 第三阶段：多航点与循环巡逻任务

### 用户操作流程

1. 加载已经验收的正式地图并完成定位。
2. 在地图上依次标记多个任意合法航点；每个航点可保存位置和箭头朝向。
3. 网站按编号显示航点顺序，并允许删除、重新排序或清空后重建。
4. 设置巡逻执行次数，例如1次、3次、5次或持续巡逻。
5. 点击“开始巡逻”，小车按照航点顺序逐点执行；到达最后一个点后按设置次数开始下一轮。
6. 网站显示当前航点、已完成航点、本轮进度、已完成轮次、总轮次和任务状态。
7. 达到设定次数后在最终航点安全停车并显示“巡逻完成”。

### 第三阶段通过标准

- 航点顺序、目标朝向和循环次数必须与网页设置一致。
- 单个航点成功后才进入下一个；失败时不得静默跳过，必须按策略重试、暂停或终止并显示原因。
- 支持暂停、恢复、取消和急停；暂停/取消/急停后底盘速度必须归零。
- 支持人工蓝牙或MQTT抢占；人工接管后ROS巡逻任务进入明确的暂停或取消状态，不能继续后台发速度。
- 至少使用多个航点完成多轮连续巡逻，验证无累计定位失控、无任务次数错误、无结束后继续运动。

## 最终交付范围冻结

客户交付主流程固定为：

```text
人工遥控完整建图
  -> 自定义名称保存并可加载
  -> 加载地图并任意点定点导航
  -> 设置目标箭头朝向并到点停车
  -> 标记多个航点
  -> 设置巡逻次数
  -> 按顺序多轮执行并最终停车
```

RGB摄像头、实时雷达、状态诊断、语音提示、地图图层、人工接管、急停、备份恢复属于支撑与安全功能；不能替代以上三阶段实车验收。只有三阶段均在实体车辆和真实场地通过，才能标记为客户交付完成。

## 车辆到货后的恢复入口

1. 先完成STM32板对板串口、编码器、ICM42670、控制权仲裁和急停验证。
2. 标定轮径、轮距、编码器CPR、左右轮方向、IMU安装方向、雷达TF和速度PID。
3. 打通稳定`/odom`、`/imu`、`/scan`和TF后，从本文件第一阶段开始执行。
4. 每完成一个阶段立即记录地图、参数、日志、截图、rosbag、失败问题和解决方法，不等待三阶段全部结束。
