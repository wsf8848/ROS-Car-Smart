# 2026-09-25 LD14障碍回波悬停距离提示

## 目标与边界

- 鼠标悬停在右下角真实LD14扫描回波附近时，显示该真实`/scan`点的距离值。
- 同时显示角度、LD14雷达坐标系X/Y和强度，命中点增加高亮圆环。
- 提示值直接来自当前LaserScan回波，不根据地图或画布比例估算。
- 当前没有`map→laser` TF，因此坐标必须明确标记为“雷达坐标”，不能冒充地图坐标。
- 不改变地图、关机/重启、任务和安全控制逻辑。
